# Overzicht implementatiebriefs

Implementatiebriefs bewaren de oorspronkelijke requirements en voorgestelde aanpak. De oorspronkelijke tekst blijft behouden; latere besluiten en afwijkingen staan in de bijbehorende featuredocumentatie.

Elke brief heeft een vaste code `BRIEF-NNN`. Gebruik die code als prefix van de bestandsnaam; nummer briefs op volgorde van het oorspronkelijke taakmoment (oud naar nieuw). Werk bij hernummering ook bestandsnamen en verwijzingen bij. De overzichtsbestanden hebben, net als het reviewoverzicht, geen volgnummer.

Timestamp vermeldt het oorspronkelijke taakbericht van de gebruiker, gereconstrueerd uit de lokale gespreksregistratie en weergegeven in Europe/Amsterdam met UTC-offset (seconden, zonder milliseconden). Dit is geen uitvoerings-, afrondings- of opvraagmoment. Latere raadpleging verandert deze datum niet.
